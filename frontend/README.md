# TechSwitch Pro - Frontend (Vite + React + Tailwind)

Modern UI for LeetCode Companywise Interview Questions & MongoDB Sync.

## 🚀 Local Setup
```bash
cd frontend
npm install
npm run dev
```

## 🌐 Deploy to Vercel / Netlify
1. **Root Directory**: `frontend`
2. **Framework Preset**: Vite
3. **Build Command**: `npm run build`
4. **Output Directory**: `dist`
5. **Environment Variables**:
   - `VITE_SYNC_SERVER_URL`: Your deployed backend URL (e.g. `https://your-backend.onrender.com`)
